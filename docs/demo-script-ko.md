# 2분 설명형 데모

이 화면의 포트폴리오는 가상이다. 거래는 실행하지 않는다.

1. 문제: Solana에 현물과 예치금이 있고 Hyperliquid에는 이를 헤지하는 숏이 있다. 전체 자산은 충분해 보여도 원하는 현금을 곧바로 꺼낼 수 있는지는 별개다.
2. 요청: Solana 지갑으로 5,000 USDC를 마련하고 싶다. 추가 대출은 하지 않고, SOL 보유 수량과 현재 헤지를 유지하고 싶다.
3. 거절: 예치금과 여유 증거금만으로는 목표가 부족하다. 현물만 매도하면 헤지가 달라지고, 증거금을 더 빼면 사용자의 여유 한도를 위반한다. 비교 엔진은 이유를 표시한다.
4. 조건 변경: SOL 수량 일부 감소는 허용하되 헤지 관계는 유지한다. 시스템이 현물과 숏을 함께 줄이는 후보를 다시 계산한다. AI 연결 시 대화로, 미연결 시 직접 조건으로 수정한다.
5. 해결: 최종 USDC, 수수료, 남은 현물과 숏, 담보 여유를 나란히 비교한다. 선택한 경로의 단계별 리허설을 연다. 실제 체결이나 송금 완료 표시를 하지 않는다.
6. 의미: 단순 잔액 집계나 브리지가 아니라 현금 목표와 남길 위험을 동시에 다루는 것이 검증할 제품 가설이다.
